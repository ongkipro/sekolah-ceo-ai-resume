Proyek ini adalah portal interaktif yang mengubah transkrip dan rekaman *masterclass* 12+ jam menjadi *executive-grade modular knowledge base* yang dapat diakses dan dieksekusi dengan cepat oleh CEO, *Founders*, dan C-Level executives.

## Quickstart

```bash
git clone https://github.com/ongkipro/sekolah-ceo-ai-resume
cd sekolah-ceo-ai-resume

# Install dependencies
pnpm install

# Start development server
pnpm run dev
```

## Key Features

- **Executive Curriculum**: Analisis sesi mendalam dengan sinkronisasi timestamp YouTube.
- **Cheatsheets**: Rangkuman 3 menit eksekutif (Lakukan Besok, Kesalahan Fatal, Master Prompt).
- **Executive Prompt Vault**: Template prompt bisnis dengan kustomisasi variabel dinamis.
- **AI Decision Simulator**: Kalkulator *headcount ROI* dan otomasi operasional.
- **Interactive Pathways**: Jalur belajar spesifik berbasis peran (CEO, CFO, CMO, COO).
